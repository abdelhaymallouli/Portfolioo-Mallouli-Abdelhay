# AI Agent Workflow (Antigravity)

This directory houses the autonomous agent logic and MCP (Model Context Protocol) configurations used in this project.

## 🚀 Overview

We utilize **Antigravity AI** to orchestrate specialized agents that handle:

- Automated recursive research
- Codebase integrity checks
- Deployment orchestration via CI/CD agents

## 🛠️ Stack

- **Framework**: Antigravity
- **Protocol**: MCP (Model Context Protocol)
- **Runtime**: Node.js / Python

## 📂 Structure

- `/prompts`: Specialized system instructions for different agent roles.
- `/tools`: Custom MCP tools for system-level interaction.
- `/memory`: Contextual persistence for long-running agent tasks.
